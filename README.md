## Livesy

### Admin app

- create token
- token list (all)

- actions on token
  freeze
  delete
  copy address to share

- add token meta (imgs, tags, description, title)

### User App

- discover tokens (how all tokens)

- actions on token
  add to wallet
  add to favorites
  my assets (all erc20 tokens owned by user(any user))
  copy address to share

- limit order
- orders list

### Anonymizer app

- mix erc20 tokens
